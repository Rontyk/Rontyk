Учусь в SDU и делаю сайты, лендинги и Telegram-ботов для малого бизнеса. В команде Оптомата пишу каталог для B2B-площадки оптовой торговли, сейчас это дерево категорий с характеристиками товаров. Бэкенд на FastAPI, фронт на Next.js.

Если нужен сайт или бот для вашего дела, пишите в WhatsApp. Первый вариант покажу через 2-3 дня.
